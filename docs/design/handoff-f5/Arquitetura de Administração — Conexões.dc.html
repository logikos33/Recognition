Pedidos ao backend — nesta ordem
P1  Usuários escopados por tenant. As rotas de usuário passam a aceitar admin:users e, nesse caso, respondem apenas com gente do tenant do token. Cross-tenant devolve 404, nunca 403 — não se vaza nem a existência. Sem isto, a tela Equipe não pode ser construída.
P2  Auditoria do próprio tenant. Recorte de audit:read limitado ao tenant. O cliente precisa saber quem desativou uma câmera e quando.
P3  Nada de rota nova para marca e papéis. Já funcionam para admin de tenant — é só construir a tela. Registrado para ninguém "criar endpoint" por engano.
