Prova de encaixe

No demo, a tela Gestão Qualidade (aprovada) renderiza intocada dentro do shell — TopBar global + sidebar de Qualidade em volta. O ajuste foi só no shell: o contêiner de conteúdo desloca a tela em −56px para absorver o header local que ela trazia como página solta. Na implementação, as telas de módulo deixam de renderizar header próprio; o shell fornece TopBar, breadcrumb e navegação. Nenhum outro pixel da tela muda.

Responsivo

Desktop-first ≥1280px — layout de referência.
1024–1280px — sidebar inicia colapsada (64px); breadcrumb encurta para os 2 últimos níveis.
Mobile <768px — sidebar vira drawer (hambúrguer); só leitura de eventos e ações (LOTE 2); busca ⌘K vira tela cheia.
/tv 1080p — sem chrome nenhum (LOTE 3).
LOTE 2 (jornada EPI, 7 telas) aguarda aprovação deste lote. O handoff vira prompts de Claude Code nas fases F1–F5.
